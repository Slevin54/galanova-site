Политика в отношении обработки персональных данных

1. Общие положения

Настоящая политика обработки персональных данных составлена в соответствии с требованиями Федерального закона от 27.07.2006. №152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению безопасности персональных данных Галановой Елены (далее – Оператор).

Оператор ставит своей важнейшей целью и условием осуществления своей деятельности соблюдение прав и свобод человека и гражданина при обработке его персональных данных, в том числе защиты прав на неприкосновенность частной жизни, личную и семейную тайну.

Настоящая политика Оператора применяется ко всей информации, которую Оператор может получить о посетителях веб-сайта http://galanova-elena.ru.

2. Основные понятия, используемые в Политике

  • Автоматизированная обработка персональных данных – обработка персональных данных с помощью средств вычислительной техники;
  • Веб-сайт – совокупность графических и информационных материалов, обеспечивающих их доступность в сети интернет по сетевому адресу http://galanova-elena.ru;
  • Обработка персональных данных – любое действие (операция) или совокупность действий (операций), совершаемых с использованием средств автоматизации или без них с персональными данными, включая сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу, обезличивание, блокирование, удаление, уничтожение;
  • Персональные данные – любая информация, относящаяся прямо или косвенно к определенному Пользователю веб-сайта;
  • Пользователь – любой посетитель веб-сайта http://galanova-elena.ru.

3. Персональные данные, обрабатываемые Оператором

Оператор может обрабатывать следующие данные Пользователя:

  • Имя;
  • Номер телефона;
  • Адрес электронной почты;
  • Обезличенные данные (в т.ч. файлы «cookie») с помощью сервисов интернет-статистики.

4. Цели обработки персональных данных

Цель обработки персональных данных Пользователя — оказание информационно-консультационных услуг, уточнение деталей заявки, обеспечение связи с Пользователем.

Обезличенные данные Пользователей служат для сбора информации о действиях на сайте, улучшения качества сайта и его содержания.

5. Правовые основания и порядок обработки

Оператор обрабатывает персональные данные Пользователя только в случае их заполнения и отправки Пользователем самостоятельно через формы на сайте http://galanova-elena.ru. Отправляя свои данные, Пользователь выражает свое согласие с данной Политикой.

Безопасность персональных данных обеспечивается путем реализации правовых, организационных и технических мер, необходимых для выполнения требований действующего законодательства. Данные Пользователя никогда не будут переданы третьим лицам, за исключением случаев, связанных с исполнением действующего законодательства.

Срок обработки персональных данных ограничен достижением целей обработки. Пользователь может в любой момент отозвать свое согласие, направив Оператору уведомление на электронный адрес kombinir@mail.ru с пометкой «Отзыв согласия на обработку персональных данных».

6. Заключительные положения

Пользователь может получить любые разъяснения по интересующим вопросам, касающимся обработки его персональных данных, обратившись к Оператору по электронной почте kombinir@mail.ru.

В данном документе будут отражены любые изменения политики обработки персональных данных Оператором. Политика действует бессрочно до замены ее новой версией.
